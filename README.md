# Báo cáo Bài 1: Kiểm tra cài đặt Docker Engine và chạy Container Hello-World

Chi tiết đầy đủ nội dung báo cáo và kết quả thực thi vui lòng xem tại tệp: [REPORT.md](./REPORT.md).

## Tóm tắt các lệnh thực hiện:
```bash
# 1. Kiểm tra phiên bản Docker
docker version

# 2. Kiểm tra thông tin cấu hình Docker daemon
docker info

# 3. Chạy container hello-world
docker run hello-world
```

Kết quả: Container hiển thị thành công thông điệp chào mừng chuẩn của Docker:
> *"Hello from Docker! This message shows that your installation appears to be working correctly."*
